### born2feel

Backend, mostly Go and Python. Lately I've been into security: I run a honeypot and look at what bots do once they think they're in.

**Projects**

- [honeynet](https://github.com/born2feel/honeynet): SSH, Telnet and HTTP honeypot in Go with a web dashboard. A fake shell keeps bots busy, sessions get grouped into campaigns, indicators export to STIX.
- [bookit](https://github.com/born2feel/bookit): Telegram bot for booking appointments with an admin panel. aiogram 3, SQLAlchemy, PostgreSQL.
- [miniapp](https://github.com/born2feel/miniapp) ([demo](https://born2feel.github.io/miniapp/)): Telegram Mini App for a beauty salon, built with Angular.
- [kraken-tracker](https://github.com/born2feel/kraken-tracker): CLI for Kraken market data that updates itself every day through GitHub Actions.
- [landing-demos](https://github.com/born2feel/landing-demos) ([demo](https://born2feel.github.io/landing-demos/)): landing pages in plain HTML and CSS.

Uni OOP labs: [WeatherBot](https://github.com/born2feel/WeatherBot), [Delivery](https://github.com/born2feel/Delivery), [WikiSearch](https://github.com/born2feel/WikiSearch), [AddressStats](https://github.com/born2feel/AddressStats).

**Stack:** Go, Python, TypeScript, Java, PostgreSQL, SQLite, Docker, GitHub Actions.
